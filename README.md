## 🎯 What is OVERSEER?

**OVERSEER** is an all-in-one desktop overlay built for **ARK: Survival Ascended** players. It runs on top of your game and gives you instant access to advanced tools without ever leaving your session — taming calculator, breeding manager, floating timers, interactive maps, OCR scanner, and much more.

> Built specifically for **ARK: Survival Ascended** — all taming values are calibrated against official ASA data.

## ⬇️ Installation

1. Go to the [**Releases**](https://github.com/haylowof-pixel/overseer-companion/releases/latest) page
2. Download **`OVERSEER.Setup.x.x.x.exe`**
3. Run the installer and follow the instructions
4. OVERSEER launches automatically after installation

> **Auto-update** — The app checks for new versions on startup and installs them on close.

## ⌨️ Keyboard Shortcuts

| Action | Shortcut |
|--------|----------|
| Show / Hide app | `Alt + T` |
| Toggle Overlay | `Alt + O` |
| Timer Overlay | `Alt + M` |
| Mini Widget | `Alt + W` |
| Cycle widget size | `Alt + Shift + W` |
| Interactive Maps | `Alt + G` |
| Breeding Manager | `Alt + B` |
| OCR Scanner | `Alt + S` |
| Quick Scan | `F8` |

> All shortcuts are **fully rebindable** in the settings.
