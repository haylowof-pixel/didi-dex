## 🎯 Qu'est-ce qu'OVERSEER ?

**OVERSEER** est une application desktop tout-en-un conçue pour les joueurs d'**ARK: Survival Ascended**. Elle s'exécute en superposition de ton jeu et te donne accès à des outils avancés sans quitter la partie : calculateur de taming, gestionnaire de breeding, timers flottants, cartes interactives, scanner OCR et bien plus.

> Conçu pour **ARK: Survival Ascended** — toutes les valeurs de taming sont calibrées sur les données ASA officielles.

## ⬇️ Installation

1. Va sur la page [**Releases**](https://github.com/haylowof-pixel/overseer-companion/releases/latest)
2. Télécharge **`OVERSEER.Setup.x.x.x.exe`**
3. Lance l'installeur et suis les instructions
4. OVERSEER démarre automatiquement après installation

> **Mise à jour automatique** — L'app vérifie les nouvelles versions au démarrage et les installe à la fermeture.

## ⌨️ Raccourcis Clavier

| Action | Raccourci |
|--------|-----------|
| Afficher / Masquer l'app | `Alt + T` |
| Toggle Overlay | `Alt + O` |
| Timer Overlay | `Alt + M` |
| Mini Widget | `Alt + W` |
| Changer taille widget | `Alt + Shift + W` |
| Cartes interactives | `Alt + G` |
| Breeding Manager | `Alt + B` |
| Scanner OCR | `Alt + S` |
| Scan rapide | `F8` |

> Tous les raccourcis sont **reconfigurables** dans les paramètres.
